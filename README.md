RenewBook 📚


Exchange Knowledge. Share Books. Make Learning Sustainable.


RenewBook is a student-driven platform designed to make exchanging books and study materials easier, more affordable, and accessible. It encourages students to share academic resources, reduce educational expenses, and promote sustainable learning.


🎯 Project Overview


Developed as a Java Micro Project, RenewBook aims to connect students who want to exchange, share, or access educational resources.
